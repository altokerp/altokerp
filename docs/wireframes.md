# Wireframes básicos — GO Move (Fase 1)

## App Pasajero

### Pantalla Home / Mapa

- Header con saludo + acceso a perfil
- Mapa full-screen con pin de origen
- Caja destino (autocomplete)
- Selector de servicio: `AUTO` | `MOTO`
- Tarifa estimada + ETA
- Botón primario: `Solicitar viaje`

### Pantalla Viaje en curso

- Datos de conductor (foto, placa, calificación)
- Estado del viaje (en camino / iniciado / finalizando)
- Tiempo estimado restante
- Botón de emergencia (SOS)
- CTA: compartir viaje

### Pantalla Historial

- Lista de viajes por fecha
- Precio final y método de pago
- Acción de calificar

## App Conductor

### Dashboard conductor

- Toggle online/offline
- Resumen ganancias del día
- Estado de validación documental

### Solicitud entrante

- Distancia al pasajero
- Tipo de servicio requerido (AUTO/MOTO)
- Tarifa estimada
- Botones `Aceptar` / `Rechazar`

### Viaje activo

- Ruta hacia recojo y destino
- Botones `Iniciar viaje` y `Finalizar viaje`

## Landing web

1. Hero con propuesta de valor y CTAs de descarga
2. Sección “Cómo funciona” (3 pasos)
3. Servicios AUTO y MOTO (cards comparativas)
4. Seguridad (verificación, SOS, soporte)
5. Contacto

## Panel Admin

- Dashboard: viajes hoy, usuarios activos, conductores online
- Tablas de gestión: usuarios, conductores, viajes
- Módulo validación documental
- Módulo tarifas/promociones
